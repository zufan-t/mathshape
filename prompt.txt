Prompt 11:
Page isi materi:
- Image Big Idea: ada di folder assets dengan masing masing bernama materiSatu, materiDua, materiTiga
- Sidebar tampilan mobile: dipindah ke navbar, ketika di klik ikon menu ada isi menu yang sebelumnya itu di sidebar. 
- Buat transisinya mulus ketika di klik selanjutnya, page selanjutnya muncul dibawahnya tapi viewnya tidak ikut ke scroll.
- Seharusnya sesuai progress yang sudah didapat. Misal kalau sudah 60% maka kalau dia kembali buka materi dia juga langsung ke page yang sebelumnya sudah 60%

Page List materi:
- Image: diambil dari image Big Idea masing-masing materi

Page Daftar:
- Form password: beri keterangan di bawah input password apa saja yang harus diinput sesuai ketentuan. Keterangan berupa list, misal - huruf kapital, - huruf kecil, - angka, - simbol (@, #, %, *, ^)

Page verifikasi email terkirim:
- Tombol Kirim ulang: perbaiki, seharusnya bukan mengarah ke page reset password melainkan sharusnya langsung saja kirim ulang link verifikasi emailnya.

Page apresiasi:
- Tombol kembali: perbaiki, seharusnya bukan ke halaman utama tetapi mengarah ke halaman list materi. Tulisan tombolnya juga diganti "Ke List Materi".
- Tombol materi selanjutnya: seharusya langsung masuk materi selanjutnya bukan kembali ke page list materi.

Page akun:
- Seharusnya disitu tertera semua data dirinya bukan malah kosongan
- Edit data diri seharusnya ketika klik edit data diri. Jadi tombol yang simpan perubahan itu harusnya 'edit data diri' dulu baru ketika di klik berubah menjadi simpan perubahan. TOmbol Batal seharusnya hanya muncul saat tombol edit di klik.
